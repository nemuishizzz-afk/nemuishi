# ねむいし、本気出す。

眠いナマケモノのお医者さん「ねむいし」が、本気を出して車をふっとばす道路わたりゲーム。

- 遊ぶ：https://nemuishizzz-afk.github.io/nemuishi/
- スマホで開いて「ホーム画面に追加」すると、アプリのように全画面で遊べます。

## ファイル
- index.html … ゲーム本体（画像も中に入っています）
- manifest.webmanifest / icon-*.png / apple-touch-icon.png … ホーム画面に追加したときのアイコン
- ogp.jpg … LINEやXでリンクを送ったときに出る画像
